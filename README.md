# Subproject 1: Marketing Reference Topics

A reference repo built from 20 marketing and brand-strategy article briefs (mostly WARC-style, 2025). Each article is summarised in its own note with key facts, takeaways and links to related notes.

> Notes are paraphrased summaries for internal reference. Check stats against the original sources (listed in each note's front matter) before citing them.

## How to use
- **Browse by category**: see the index below.
- **Build an argument**: [themes.md](themes.md) groups articles by cross-cutting idea.
- **Reuse a model**: [frameworks.md](frameworks.md) collects the frameworks and checklists.
- **Find a number fast**: [stats.md](stats.md).
- **Add a new article**: copy [_template.md](_template.md) into the right `topics/` folder and add a row below.
