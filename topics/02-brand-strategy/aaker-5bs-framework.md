# The 5Bs branding framework

## TL;DR
Dave Aaker (vice chairman, Prophet) updated *Aaker on Branding* (first edition 2014) with the **5Bs framework** – a roadmap for relevance, loyalty and brand equity in a world of fragmented attention, clutter and scepticism.

## The core shift
> The assignment is **relevance**, not awareness. Branding is not just a communication task to build awareness and image.

Branding today involves:
1. An image concept that goes **beyond functional benefits**.
2. Recognising that loyalty is shaped by **customer experience and relationship**.
3. Working as a **brand team** – never a standalone brand.
4. Treating brand equity as an **asset to be managed and leveraged**.

## The 5Bs
| B | Role |
|---|---|
| **Brand equity** | The centre: owned brand assets that enable new and existing strategies |
| **Brand relevance** | Drives equity |
| **Brand image** | Drives equity |
| **Brand loyalty** | Drives equity |
| **Brand portfolio** | Builds and supports relevance, image and loyalty |

```
          Brand portfolio
                │ supports
   ┌────────────┼────────────┐
Relevance     Image       Loyalty
   └────────────┼────────────┘
                ▼ drive
           BRAND EQUITY
```

Each B shapes customer perceptions and decisions, motivates employees and stakeholders, and has uses and risks that have changed significantly in the past decade.

## How to use it
- Audit a brand against each B; identify which is weakest.
- Use as a lens on the case studies in this repo (e.g. Sephora = loyalty via experience; Goodles = image; Kraft Heinz = relevance).
